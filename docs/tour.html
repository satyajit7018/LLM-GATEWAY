Two-layer caching

Exact-match for identical prompts, semantic (cosine similarity) for reworded ones — repeated and near-duplicate questions cost ~0ms and 0 tokens.

Streaming responses

Token-by-token replies with Stop / Regenerate, an edit-and-resend on any past message, and graceful auto-retrying instead of raw errors.

Multi-provider routing

Groq, Google Gemini, OpenRouter, Mistral and more — pick a model per message; each caches separately, so nothing crosses providers by accident.

Vision + documents

Attach photos or camera shots and it auto-routes to a vision-capable model; PDFs and text files are read straight into the prompt.

Resilience

Token-bucket rate limiting, exponential-backoff retries, and a circuit breaker — a failing provider can't cascade into a broken chat.

Live cost dashboards

Per-model usage and cost, cache hit-rate, and latency — durable and server-backed, visible right from the chat header.

Your account, your keys, your quota

access

Free everyday models are included for anyone with an account. Bring your own API key for a provider and its premium models unlock instantly — billed to you, not the app.

Accounts, done properly

Signup/login, email verification, forgot/reset password, change password, sign out everywhere, and delete account — all self-serve from Settings.

Bring your own key

Add a provider's API key to unlock its models. The key is validated with a real test call before it's ever saved, so a typo gets caught immediately, not later.

Free daily quota

A per-user daily token allowance on the app's shared models, with a live usage bar in Settings and a quiet warning toast as you approach it.

A real code workspace, not a code block

build mode

Turn on Build and the model writes runnable projects instead of chat text — rendered live, checked automatically, and editable in a proper multi-file IDE, all inline below the conversation.

Live sandboxed preview

Every answer auto-runs in a sandboxed frame and self-checks for console errors — a pass/fail chip lands right on the chat message.

writing code…→ running & checking…→ ✓ runs clean

Multi-file Monaco editor

The same editor core as VS Code, vendored offline and loaded on demand — real IntelliSense for JS/TS/CSS/HTML/JSON and Python via Jedi, plus project-wide search.

Console, Terminal, Files, Diff

Tabs for runtime console output, a real local terminal, a workspace file browser, and a reviewable diff when a Build touches an already-open project.

Local execution

Real interpreters — Python, Node, Bash, Ruby — with interactive stdin, pip/npm installs, and a persistent per-project workspace. Loopback-only by default.

"Fix it with AI"

A real traceback becomes an inline editor marker on the failing line, and one click feeds the actual error back to the model to re-prompt and re-run.

Screenshot → code

Attach a design reference or screenshot in Build mode and it's read as a layout to reproduce, not just an image to describe.

Publish

One click gets a stable, shareable link to the rendered page — hosted by the same server, no third-party deploy account required.

Revert to any checkpoint

Every message that changed the code carries a snapshot of the project at that point — one click restores it exactly, no matter what's changed since.

Every code tab, grouped into Not started / In progress / Needs fix / Done — status is live, drag a card to override it manually.

Goal notes

Attach a short note to any task describing what it's actually for, separate from the chat title — click a card to edit it inline.

Fork a task

Clone a task's current project into a new, independently-running one — try two different approaches to the same starting point.

Merge review

Diff a forked task against its original file by file, pick "keep mine" or "keep theirs" per changed file, and apply the result.

Real background concurrency

Start a Build, switch to a different task, start another — both actually run at once. Come back and its live-preview check has already finished too.
